# Clawd の動きと絵

プロンプトの上のカードに出る Clawd（Claude Code のキャラクター）は、**会話の重さとキャッシュの状態**を一目で伝えるためのもの。数字を読まなくても、動きで分かる。

← [README](../README.md)

## 動きの意味

| 状態 | 絵 | いつ |
|---|---|---|
| 眠る（息をして、z が増えたり減ったり） | 地面に伏せて目を閉じる | ① セッションを始めてから、最初の言葉を送るまで。② **プロンプトキャッシュが切れたとき**（下） |
| 歩く・小走り | 左右に揺れながら足を出す | 会話が小さい〜中くらい |
| 走る・全力 | 跳ねながら腕を振って走る | 会話が育ってきた |
| 汗 | 目をぎゅっと閉じて、汗のしずくを飛ばして走る | **走る速さが最高になったとき**（会話が重い） |
| ジャンプ | かがんで、両腕を V の字に上げて跳び、∩ ∩ の目で喜ぶ。星が出る | **要約したとき**（`/compact`・自動要約・ペインの「要約する」）と **`/clear` したとき** |

Clawd の横の一言（「のんびり歩いています」など）も、同じ状態に合わせて変わる。

### 眠る: キャッシュが切れたとき

Claude は、会話の前の部分を**プロンプトキャッシュ**に置いて、次のリクエストで安く読み直す。このキャッシュは、最後のリクエストから一定の時間がたつと消える。**消えたら Clawd は眠る**。眠ったあとは、アニメの処理も止まる（何も再描画しない）。

- 最後のリクエストが返った時刻、言葉を送った時刻、ツールを呼んだ時刻のどれかから数える。
- キャッシュの寿命は、**API キーなら 5 分、サブスクリプションなら 60 分**。`cacheTtlMinutes` で変えられる（0 は自動）。
- 次の言葉・ツール呼び出し・リクエストで目を覚ます。
- 眠るまでは、アニメが動き続ける（コマ送りのタイマーが回る）。キャッシュの寿命が長いサブスクリプションでは、最後の操作から最大 60 分、動き続けることになる。気になるときは `cacheTtlMinutes` を短くするか、`/config` の「Reduce motion」をオンにする。
- 起動直後や、前の会話を再開した直後は、まだキャッシュがないので眠っている。最初の言葉で起きる。
- プラグインを読み込み直しても（`/reload-plugins` や、開発中の保存）、直前のターンからの経過時間で状態を引き継ぐ。

### 走る速さ: 会話の大きさ

会話が大きいほど速く走る。大きさの目盛りは、枠の色・要約の提案と同じものを使う。

- **目盛り:** 20 万 tok を満杯とみなす（窓が 20 万より小さければ窓）。返信のたびに会話全体を読み直すので、窓が 100 万あっても重さは変わらないため。
- **いちばんゆっくり:** 空のセッションがもともと持っている分（プロンプト・ツール・スキルなど。最初の返信で測る）に、約 2 万 tok を足した大きさまで。
- **最高速:** 満杯の **90%**（20 万基準で約 18 万 tok）。ここで汗が出る。要約の提案が強くなる点と同じ。
- その間は、大きさに比例して速くなる。1 コマの間隔は 260 ms（ゆっくり）から 70 ms（最高速）。

| 速さ | 呼び名 |
|---|---|
| 0〜0.2 未満 | 歩く |
| 0.2〜0.5 未満 | 小走り |
| 0.5〜0.8 未満 | 走る |
| 0.8 以上、最高速の手前 | 全力 |
| 最高速 | 全力 + 汗 |

枠の色は、約 14 万 tok で黄、約 18 万 tok で赤になる（窓が 20 万以下なら窓の割合のまま）。

## 絵

端末によって、Clawd は画像かブロック文字になる。同じ点から作るので、形も動きも同じ。

- **画像:** 画像が描ける端末（Ghostty で確認済み。kitty も対応のはず）。1 点を 8×16 ピクセルで描いた PNG（256×160）。
- **ブロック文字:** 画像のない端末。四分割ブロックで 16×5 マス。Orca や tmux の中は、こちら。
- **顔だけの帯:** 幅が 56 桁未満の帯、デスクトップ版、高さが足りないとき（下）。色つきの絵の代わりに、顔を出す。数字はカードと同じで、折り返して複数行になることがある。`<[･_･]>`（軽い）／`<[o_o]>`（少し重い）／`<[>_<]>`（いっぱい）／`<[-_-]>`（要約中）。顔は文脈の重さか、助言の強いほうで決まる。幅が変わる文字は使わず、半角だけで作る。

### 画像を使うかどうかの判断

端末の名乗りで最初に当たりをつけ、最初の描き込みに端末が応じれば確定する。応じなければ（代わりの文字しか出せない端末）、ブロック文字に戻る。

| 見るもの | 結果 |
|---|---|
| `TOKENOMICS_CAT_IMAGE=1` | 画像を試す |
| `TOKENOMICS_CAT_IMAGE=0` | 画像を使わない |
| `TMUX`（tmux の中） | ブロック文字（tmux は画像を通さない） |
| `ORCA_IMAGE_PROTOCOL=kitty`、`KITTY_WINDOW_ID`、`GHOSTTY_RESOURCES_DIR`、`TERM_PROGRAM` が ghostty か kitty | 画像を試す |
| それ以外 | ブロック文字 |

### Reduce motion

`/config` の「Reduce motion」をオンにすると、Clawd は動かない。状態ごとの絵が 1 枚出るだけ（タイマーなし、ジャンプなし。ペインのデモも出ない）。

### 状態を確かめる

`/tokenomics settings` の「Clawd のようす」で、会話の大きさに関係なく、寝る・歩く・小走り・走る・全力・汗・ジャンプを試せる（12 秒間）。

## 絵を直す

絵は **32×10 の点**で、`mods/tokenomics/hooks/lib/clawd.ts` に書いてある。1 点は半マスの幅 × 半マスの高さ（四分割ブロックの 1 マスが 2×2 点）。

- 1 つの体（幅 16 点・高さ 6 点の胴、四隅の足、脇の腕、2 つの目）を、ずらす・縮める・足の長さや腕の高さや目を変える、で動かしている。足は 2 点（1 マス分）の長さ。
- Claude Code の起動画面の Clawd と同じ作り（体、脇の腕、四隅の足、縦長の黒い目）。縦を 1 点伸ばして、幅 4 : 高さ 3 のずんぐりしない体にしてある。
- マスは 2 色までしか持てないので、どのマスも 2 色以内に収まるように描く（テストで確かめている）。`z` `Z` `+` `*` は、ほかに何もないマスに文字で置く。
- 直したら、`bun mods/tokenomics/tools/clawd/make-clawd.ts` を実行する。画像の `hooks/lib/cat-art.ts` が作り直される。PNG のパスを渡すと、全コマを並べた見本も書く。ブロック文字は点からそのまま描かれるので、実行が要るのは画像のためだけ。
- 絵の変更は、見本の画像を見て決める。「猫に見えるか」「角ばっていないか」を、数値ではなく見た目で判断する。

## カードの行

カードは、枠を入れて **7 行**（Clawd の 5 行 + 枠）。左に Clawd、右に数字の行が並ぶ。

- 右の列: ゲージ → 現在のセッションの合計 → 現在のターンの合計（2 行）→ ボタンと一言。一行の提案か助言が出ているときは、Clawd の一言の代わりにそれが入り、折り返せばさらに行が増える。
- ターンがまだないうちは、セッションもターンも `—` の 1 行ずつ。
- ペインを開いて帯が狭くなると、数字の行が折り返す。折り返した行の間に空行は入れない。
- 「現在のターンの合計」が折り返すほど狭いときだけ、行の名前を「今回」「セッション」に縮める。
- **高さが足りないとき:** カードは 7 行以上使う。端末が低くて入らないときは、顔だけの帯に切り替える。提案のカードが上に出ているときは、その分（8 行）を引いて判断する。提案のボタンが画面の外へ押し出されないため。
