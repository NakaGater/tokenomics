# 実機で確かめたこと・まだのこと

説明文書に書いた動きのうち、**実機で見たもの**と、**テストやコードからの推定だけのもの**の一覧。「確かめた」は、その日付のその操作で見えたことで、ほかの環境や版でも同じとは限らない。

← [README](../README.md)

## 既知の注意

- **プラグインを読み込み直すと、帯の「節約（延べ）」は 0 から数え直す。** 縮めた分の記録がメモリ上にあるため。入力・出力・ターンは残り、今日の合計は台帳に残る。
- **サブスクリプションでは、Clawd のアニメが最後の操作から最大 60 分動き続ける**（キャッシュの寿命が 60 分のため）。
- 委任の推定の係数（実際の増え分の 1/2〜1/4）は、1 つの質問・3 回の測定だけが根拠。
- 実測の数字（サブエージェントの最初の起動が 2〜3 万 tok、アドバイザーの出力が 5〜10k tok など）は、この PC の数回の測定。
